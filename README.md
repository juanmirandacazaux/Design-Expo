PropConnect Expo Website

A modern multi-section event website built using HTML, CSS, and Vanilla JavaScript.
This project demonstrates how to build a responsive, animated, single-page style website without frameworks.

The website simulates a professional design and architecture expo event site with multiple sections, modern UI, and interactive elements.

🚀 Features

Responsive layout for desktop and mobile

Smooth SPA-style navigation

Scroll reveal animations

Parallax hero effect

Dark / Light theme toggle

Mobile hamburger navigation

Event agenda section

Speakers showcase

Product / solutions section

Pricing / ticket section

Testimonials

FAQ section

Contact form

Animated page loader

Clean modern UI

🛠 Technologies Used

HTML5

CSS3

Vanilla JavaScript (ES6)

No frameworks or libraries are required.

⚙️ How to Run the Project

Download or clone the repository

git clone https://github.com/yourusername/propconnect-expo-website.git

Navigate to the project folder

cd propconnect-expo-website

Open the project

Simply open index.html in your browser.

Example:

double click index.html

Or use a local server such as VS Code Live Server.

💻 Development Setup (Recommended)

If using Visual Studio Code:

Install the extension Live Server

Right click index.html

Click Open with Live Server

This will enable auto refresh while editing.
